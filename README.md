# Hammarby Sjöstad

A simple, responsive neighbourhood guide to Hammarby Sjöstad, Stockholm. Built with HTML and CSS, with an original SVG waterfront illustration.

## Preview locally

Run `python3 -m http.server 8080 --directory dist`, then open http://localhost:8080.

## Live website

https://pferda.github.io/my-first-project/

GitHub Pages serves the root of the `main` branch.

## Edit

All page content and styling are in `dist/index.html`. The root `index.html` is the matching GitHub Pages entry point; keep both copies in sync. No dependencies or build step are required.

Content sources are linked in the page footer.
